# Only Vans Website

Professional van mechanic shop and sales website.

## Quick Start

This is a static site that deploys to Vercel.

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to vercel.com
3. Import the GitHub repo
4. Deploy

That's it!

## Local Development

Open `index.html` in your browser to preview.

## Customization

Edit `index.html` to add:
- Contact form
- Gallery
- Pricing
- More pages
